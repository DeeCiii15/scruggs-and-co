# Scruggs & Co — Visual System v2

## Concept: “Field Ledger”

A documentary photographer’s brand that feels like a handbound field notebook meets a quiet gallery wall — warm from Liv’s photos, cool and modern in the chrome. Not cream/terracotta wedding-template, not dark-mode luxury, not pill-nav SaaS.

### Inspiration pulled (not copied)

| Source | Borrowed idea |
|--------|----------------|
| Jen Huang | Quiet left-weighted type columns, italic intros, extreme breath, text-as-UI |
| Perry Vaile | Script+serif brand lockup, single strong photo focal, sandy-neutral calm |
| Erin Kate | Fine-art spacing, refined all-caps nav type, photo as the room |
| Meg Smith | Centered masthead rhythm, tracked sans links, gallery-first hierarchy |
| Elizabeth Messina | Image-led pacing, restrained chrome, editorial carousel confidence |

### Type

- **Display:** Instrument Serif — editorial, soft, not fashion-Didot
- **Script accent:** Pinyon Script — only for “Liv” / small flourishes
- **UI / body:** Figtree — friendly geometric, readable

### Layout language

1. **Hero** — full-bleed photo, brand as hero signal, text CTAs (not chunky pills)
2. **Intro** — asymmetric photo collage (large + stacked), italic lead
3. **About** — edge-to-edge split, script “hello,” big display name
4. **Galleries** — featured wide cover + secondary strip (no bordered cards)
5. **Reviews** — night band, oversized italic pull-quotes
6. **Nav** — centered masthead, tracked links, underline hover (no pill shell)

### Motion

1. Image ken-burns settle on load (scale 1.06 → 1)
2. Section text fade-up
3. Link underline draw
4. Hero crossfade
